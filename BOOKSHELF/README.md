# BookShelf

Application Flutter pour gérer une bibliothèque personnelle de livres.

## Fonctionnalités

- recherche et filtrage
- écran de détail avec données passées en paramètre
- formulaire d’ajout avec validation
- thème clair/sombre
- interface responsive

## Lancement

```bash
flutter pub get
flutter run
```

## Structure

- lib/screen : écrans de l’application
- lib/widgets : widgets réutilisables
- lib/data : données mockées
- lib/models : modèles de données
- lib/routes : configuration GoRouter
